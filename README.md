### Hi, I'm Aly Raffauf

I put Linux on things that have no business running Linux, then keep them running with NixOS. I am often doing too many things at once, and typically make it happen in Go, Python, Typescript, and Rust.

**Recent Projects**

- **[switchyard](https://github.com/alyraffauf/switchyard)**. Rules-based browser launcher. Available on [Flathub](https://flathub.org/en/apps/io.github.alyraffauf.Switchyard).
- **[tg](https://tangled.org/aly.codes/tg)**. CLI Client for Tangled, the AT Protocol git forge.
- **[atbbs](https://github.com/alyraffauf/atbbs)**. Decentralized web forums built on Atproto.
- **[blzrd](https://github.com/alyraffauf/blzrd)**. Super fast NixOS fleet deployment tool.
- **[tartarus](https://github.com/alyraffauf/tartarus)**. Sandboxed, declarative AI agent harnesses with Nix.
